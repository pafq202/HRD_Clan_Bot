# 🎮 HRD Clan Bot

배틀그라운드에서 함께 플레이할 팀원을 구하는 디스코드 봇입니다.

## 📋 기능

- **구인 양식 설정**: 게임 시간, 게임 종류, 모집 인원, 음성 채널을 선택
- **구인 시작**: @here 태그와 함께 구인 메시지 자동 발송, 작성자 자동 표시
- **동시 다중 구인**: 여러 유저가 동시에 `/양식`을 사용해도 서로의 설정이 섞이지 않음
- **참여/취소**: 버튼을 클릭하여 참여 가능
- **구인 수정**: 본인이 작성한 구인 공고의 설정을 다시 입력하여 수정
- **구인 삭제**: 본인이 작성한 구인을 선택하여 삭제 (관리자/서버 주인은 전체 삭제 가능)
- **삭제 알림**: 관리자가 타인의 구인 공고를 삭제하면 작성자에게 DM으로 알림
- **데이터 저장**: 봇 재시작 후에도 참여 정보 유지
- **초대 링크 공유**: 팀원들에게 봇 초대 링크 공유

## 🚀 설치 방법

### 1. 저장소 클론
```bash
git clone https://github.com/pafq202/HRD_Clan_Bot.git
cd HRD_Clan_Bot
```

### 2. 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 환경 설정
`.env` 파일을 생성하고 다음을 추가하세요:
```
DISCORD_TOKEN=YOUR_BOT_TOKEN_HERE
```

### 4. 봇 실행
```bash
python main.py
```

## 📖 사용 방법

### 🎯 배틀그라운드 구인 기능

#### **Step 1️⃣: `/양식` 명령어 입력**
구인 설정을 시작합니다. 유저마다 독립적인 설정 세션이 생성되므로, 다른 사람이 동시에 `/양식`을 사용해도 서로 영향을 주지 않습니다.

```
⚙️ 배틀그라운드 구인 설정
아래 버튼을 눌러 게임 시간과 종류 및 인원, 음성 채널을 선택 입력하세요!

1️⃣ 시간 설정 버튼 클릭
2️⃣ 종류 설정 버튼 클릭
3️⃣ 인원 설정 버튼 클릭
4️⃣ 채널 선택 버튼 클릭

모든 설정을 완료하면 자동으로 구인이 시작됩니다! 🚀

[시간 설정] [종류 설정] [인원 설정] [채널 선택]
```

#### **Step 2️⃣: 각 버튼 클릭하여 설정**

##### **1) [시간 설정] 버튼**
게임을 시작할 시간을 입력합니다.
```
예시: 오후 6시, 오후 1시, 밤 11시, 아침 10시 등
```
✅ 완료되면 자동 알림: `✅ 게임 시간이 '오후 6시'로 설정되었습니다!`

##### **2) [종류 설정] 버튼**
게임 종류를 입력합니다.
```
예시: 일반, 경쟁, 미니게임, 커스텀 등
```
✅ 완료되면 자동 알림: `✅ 게임 종류가 '경쟁'으로 설정되었습니다!`

##### **3) [인원 설정] 버튼**
모집할 인원을 입력합니다. (2~4명만 가능)
```
2 = 듀오 (2명)
3 = 트리오 (3명)
4 = 스쿼드 (4명)
```
✅ 완료되면 자동 알림: `✅ 모집 인원이 4명(스쿼드)으로 설정되었습니다!`

##### **4) [채널 선택] 버튼**
드롭다운에서 게임할 음성 채널을 선택합니다.
```
🎮 음성채널1
🎮 음성채널2
...
```
✅ 모든 설정 완료 → **자동 구인 시작! 🚀**

#### **Step 3️⃣: 구인 메시지 자동 발송**

설정이 모두 완료되면 자동으로 구인 메시지가 발송되며, 작성자가 1번 슬롯에 자동으로 등록되고 작성자 정보가 표시됩니다.

```
@here 🎮 배틀그라운드 스쿼드 구인이 시작되었습니다! (스쿼드 - 오후 6시 - 경쟁)

┌─────────────────────────────┐
│ 배틀그라운드 스쿼드 모집       │
├─────────────────────────────┤
│ 🎮 BATTLEGROUND              │
│ ✍️ 작성자: <@USER1>           │
│ 게임 시간: 오후 6시           │
│ 게임종류: 경쟁                │
│ 📍 음성채널: #음성채널1         │
│ 모집 인원: 4명                │
│                              │
│ 참여인원                      │
│ 1. <@USER1>                 │
│ 2.                          │
│ 3.                          │
│ 4.                          │
│                              │
│ [참여]       [참여취소]        │
└─────────────────────────────┘
```

#### **Step 4️⃣: 팀원들이 [참여] 버튼 클릭**

```
1️⃣ 첫 번째 팀원 [참여] 클릭
   ✅ 참여가 완료되었습니다! (2번 슬롯)

2️⃣ 두 번째 팀원 [참여] 클릭
   ✅ 참여가 완료되었습니다! (3번 슬롯)

구인 메시지가 자동 업데이트됨!

1. <@USER1>
2. <@USER2>
3. <@USER3>
4.
```

#### **Step 5️⃣: 참여 취소**

참여를 취소하려면 [참여취소] 버튼을 클릭합니다.

```
✅ 참여가 취소되었습니다.

구인 메시지가 자동 업데이트됨!

1. <@USER1>
2.
3. <@USER3>
4.
```

#### **Step 6️⃣: 구인 수정 - `/수정` 명령어**

본인이 작성한 구인 공고의 설정을 다시 입력하고 싶을 때 사용합니다. 관리자/서버 주인은 모든 공고를 수정할 수 있습니다.

```
/수정 입력
  ↓
📋 진행 중인 구인 목록
수정할 구인을 선택하세요:

[▼ 오후 6시 - 경쟁 (4명) (5분 전) - 작성자: 유저A]
  ↓
구인 선택
  ↓
⚙️ 구인 공고 수정
아래 버튼으로 시간, 종류, 인원, 음성 채널을 모두 다시 입력하세요!
[시간 설정] [종류 설정] [인원 설정] [채널 선택]
  ↓
4개 항목 모두 입력 완료
  ↓
✅ 구인 공고가 수정되었습니다!
(기존 구인 메시지가 새로운 설정으로 즉시 반영됨)
```

> ⚠️ `/수정`은 구인 공고가 올라온 채널에서 실행해야 합니다.
> ⚠️ 모집 인원을 줄이면 초과된 참여자는 자동으로 제외되고, 늘리면 빈 슬롯이 추가됩니다.

#### **Step 7️⃣: 구인 삭제 - `/삭제` 명령어**

구인을 종료하려면 `/삭제` 명령어를 입력합니다. **본인이 작성한 공고만** 목록에 표시되며, 관리자/서버 주인은 모든 공고를 볼 수 있습니다.

```
/삭제 입력
  ↓
📋 진행 중인 구인 목록
삭제할 구인을 선택하세요:

[▼ 오후 6시 - 경쟁 (4명) (5분 전) - 작성자: 유저A]
  ↓
구인 선택
  ↓
❌ 구인 메시지 삭제
❌ 목록 메시지 삭제
  ↓
✅ 구인이 삭제되었습니다!
(3초 후 자동 삭제)
```

본인이 작성한 공고가 없는 경우:
```
❌ 구인 메시지 없음
삭제할 수 있는 구인 공고가 없습니다 (본인이 작성한 공고만 삭제 가능합니다).
```

> 💡 **관리자/서버 주인이 다른 사람의 공고를 삭제하면**, 작성자에게 자동으로 DM 알림이 전송됩니다 (어느 서버의 어떤 공고가 삭제되었는지 안내). 작성자가 DM을 막아둔 경우 알림만 생략되고 삭제는 정상 처리됩니다.

#### **Step 8️⃣: 초대 링크 공유 - `/초대링크` 명령어**

팀원들에게 봇을 초대할 수 있는 링크를 공유합니다. (관리자 또는 서버 주인만 사용 가능)

```
/초대링크 입력
  ↓
🔗 HRD Clan Bot 초대 링크
아래 링크를 클릭하여 봇을 서버에 초대하세요!

✅ 봇 권한: 메세지 보내기, 모두 멘션하기, 링크 임베드
✅ 메세지 보내기 및 멘션 기능정도만 작동합니다

🚀 빠른 시작
1. 위의 링크를 클릭하여 봇 초대
2. /양식 명령어로 구인 시작
3. /수정 명령어로 본인 구인 공고 설정 변경
4. /삭제 명령어로 본인 구인 공고 삭제
5. 팀원들과 함께 플레이!

[봇 초대하기] ← 클릭
```

### **한눈에 보기 - 전체 프로세스**

```
🔗 초대 링크로 봇 추가
  ↓
/양식 명령어 입력
  ↓
설정 4개 완료 (시간, 종류, 인원, 채널)
  ↓
구인 메시지 자동 발송 (@here 포함, 작성자 자동 표시)
  ↓
팀원들 [참여] 버튼 클릭
  ↓
인원 모두 모이면 준비 완료! 🎮
  ↓
필요하면 /수정 명령어로 내용 변경
  ↓
게임 시작!
  ↓
/삭제 명령어로 구인 종료
```

### ✅ **주의사항**

- ⚠️ 인원 설정은 **2~4명**만 가능합니다
- ⚠️ 같은 사람은 **중복 참여 불가**
- ⚠️ 설정 메시지는 완료 시 자동 삭제됩니다
- ⚠️ 구인은 **본인 작성 공고만** `/삭제` · `/수정` 가능 (관리자/서버 주인 제외)
- ⚠️ `/수정`·`/삭제`는 **구인 공고가 올라온 채널**에서 실행해야 합니다
- ⚠️ 참여/참여취소 메시지는 **3~10초 후 자동 삭제**
- ⚠️ 관리자가 타인의 공고를 삭제하면 작성자에게 **DM 알림**이 전송됩니다 (DM이 막혀있으면 알림만 생략)
- ⚠️ 여러 유저가 **동시에 `/양식`을 사용해도 서로의 설정이 섞이지 않습니다**

### 🔧 **봇 권한**

초대 링크에 포함된 필수 권한:

| 권한 | 필요 여부 | 용도 |
|------|---------|------|
| 메시지 보내기 | ✅ 필수 | 구인 메시지, 안내 메시지 발송 |
| 메시지 관리 | ✅ 필수 | 구인 메시지 삭제 (`/삭제` 명령어) |
| 모두 멘션하기 | ✅ 필수 | @here 태그 사용 |
| 반응 추가 | ✅ 필수 | 버튼 기능 (참여, 참여취소) |

## 🎓 FAQ

### Q1: 봇이 메시지를 보내지 않아요
**A:** 다음을 확인하세요:
- 봇이 서버에 초대되었나요?
- 봇이 메시지 보내기 권한을 가지고 있나요?
- `.env` 파일에 올바른 토큰이 있나요?

### Q2: 구인을 만들 수 없어요
**A:** `/양식` 명령어로 4가지 설정을 모두 완료해야 합니다:
- 시간 설정 ✅
- 종류 설정 ✅
- 인원 설정 ✅
- 채널 선택 ✅

### Q3: 참여한 팀원을 삭제할 수 있나요?
**A:** 구인 메시지를 완전히 삭제하려면 `/삭제` 명령어를 사용하세요. 개인 참여만 취소하려면 [참여취소] 버튼을 사용하세요.

### Q4: 한 번에 여러 구인을 만들 수 있나요?
**A:** 네! 여러 채널에서 동시에 여러 구인을 만들 수 있고, 여러 유저가 동시에 `/양식`을 사용해도 각자의 설정이 독립적으로 처리되어 서로 섞이지 않습니다.

### Q5: 구인 데이터는 어디에 저장되나요?
**A:** `data/pending_recruitment.json` 파일에 저장되며, 작성자 정보를 포함해 봇을 재시작해도 유지됩니다.

### Q6: 다른 사람이 만든 구인 공고를 삭제하거나 수정할 수 있나요?
**A:** 기본적으로는 본인이 작성한 공고만 `/삭제`·`/수정`할 수 있습니다. 서버 관리자나 서버 주인은 예외적으로 모든 공고를 삭제·수정할 수 있으며, 관리자가 타인의 공고를 삭제하면 작성자에게 DM으로 알림이 전송됩니다.

### Q7: `/수정`은 어디서 실행해야 하나요?
**A:** 구인 공고가 올라온 채널에서 실행해야 합니다. 다른 채널에서 실행하면 해당 메시지를 찾지 못해 수정이 실패할 수 있습니다.
